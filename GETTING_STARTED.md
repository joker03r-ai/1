# BotPilot — с чего начать

Конструктор чат-ботов для Telegram и соцсетей: живой AI-бот, визуальные
сценарии, сбор заявок, оплата и рассылки. Эта инструкция — как запустить проект
и как собрать первого бота. Полная версия доступна прямо в кабинете: раздел
**Документация**.

## 1. Запуск проекта

```bash
npm install
npm run dev        # http://localhost:3000

# продакшн-сборка
npm run build
npm run start
```

## 2. Переменные окружения

| Переменная | Назначение | Обязательна |
|---|---|---|
| `ANTHROPIC_API_KEY` | Ответы бота и сборка сценариев через Claude | нет* |
| `ANTHROPIC_MODEL` | Модель (по умолчанию `claude-haiku-4-5-20251001`) | нет |
| `ANTHROPIC_BASE_URL` | Свой эндпоинт API (по умолчанию `https://api.anthropic.com`) | нет |

\* Без ключа сервис работает во встроенном режиме: заглушки для чата и
сборка сценариев по ключевым словам. Всё остаётся кликабельным и рабочим.

Локально создайте `.env.local`:

```
ANTHROPIC_API_KEY=sk-ant-...
```

## 3. Первый бот за 6 шагов

1. **Создайте бота** — раздел «BotPilot AI» → «Создать бота». Токен берётся у
   [@BotFather](https://t.me/BotFather) (`/newbot`) и вставляется на вкладке «Каналы».
2. **Обучите** — вкладка «Обучение»: инструкция и база знаний.
3. **Соберите сценарий** — раздел «Сценарии» → «Создать» (визуальный редактор)
   или кнопка **«✨ Собрать ИИ»** — опишите бота словами, схема соберётся сама.
4. **Настройте заявки** — менеджеры, переменные, интеграции (Google Таблицы, ЮKassa).
5. **Опубликуйте** — кнопка «Опубликовать» в редакторе.
6. **Следите за результатом** — «Статистика», «Пользователи», «Рассылки».

## 4. Конструктор сценариев

Сценарий — граф из блоков, соединённых стрелками. Блоки берутся из палитры
сверху; кнопка **«Упорядочить»** аккуратно раскладывает схему сверху вниз
(древовидная раскладка: линейные цепочки — вертикально, ветки — симметрично).

Группы блоков: **События** (Старт, Комментарий, Сообщение), **Действия**
(Ответ, Обработать, Переменная, Менеджеру, Google Табл., Статистика, Рандом,
BotPilot AI), **Логика** (Подписка, Условие).

## 5. Развёртывание на сервере

Проект собирается в Docker (`output: "standalone"`). Автодеплой настроен через
GitHub Actions: после коммита в рабочую ветку образ пересобирается и контейнер
перезапускается на сервере. Секреты (доступ к серверу и `ANTHROPIC_API_KEY`)
хранятся в **GitHub → Settings → Secrets**. Подробности — в [DEPLOY.md](./DEPLOY.md).

## 6. Где хранятся данные

В текущей версии настройки кабинета, сценарии и справочники хранятся в браузере
(`localStorage`). Для командной работы данные выносятся на серверное хранилище.
