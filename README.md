# Smartbot AI — конструктор AI-ботов

Веб-приложение (личный кабинет) для создания AI-чат-ботов — воссоздание интерфейса и логики
сервиса **Smartbot AI** по скриншотам и документации. Сделано на **Next.js 14 (App Router) + TypeScript**.

## Что реализовано

- **Каркас кабинета**: сайдбар (Smartbot AI, Сценарии, Nocode Cloud, Рассылки, Чаты,
  Пользователи, Магазины, Статистика, Интеграции, Документация), блок подписки, топбар с хлебными крошками.
- **Страница бота** с вкладками:
  - **Инструкция / Обучение AI** — форма настроек: имя, выбор модели, цель
    (*Проконсультировать* / *Получить телефон*), база знаний, инструкция диалога,
    доп. контекст, сайты для обучения, загрузка PDF, тумблер «Отображать источники».
  - **Подключение каналов** — Telegram, ВКонтакте, WhatsApp, MAX, Jivo, виджет на сайт,
    Avito, Одноклассники + расширенные настройки и стоп-слово оператора.
  - **Баланс** — таблица тарифов по моделям (входящие/исходящие/кэшированные токены),
    выбранная модель, история списаний.
- **Живой AI-чат** (как в оригинале, справа от настроек):
  - Отвечает по заданной **базе знаний** бота.
  - Режим **«Получить телефон»** — мягко запрашивает контакт.
  - **Стоп-слово** (`Оператор`) — передаёт диалог оператору.
  - Счётчик **100 бесплатных тестовых сообщений**.

## AI-движок

Логика ответов — в `lib/ai.ts`:

- Если задан `ANTHROPIC_API_KEY` — отвечает реальная модель **Claude**.
- Без ключа работает **демо-режим (mock)**: простой поиск по базе знаний + скрипт по цели бота.
  Приложение полностью работает из коробки без ключей.

## Запуск

```bash
npm install
cp .env.example .env.local   # по желанию впишите ANTHROPIC_API_KEY
npm run dev                  # http://localhost:3000
```

Продакшн:

```bash
npm run build && npm run start
```

## Структура

```
app/
  layout.tsx, globals.css      # оболочка и дизайн-система
  page.tsx                     # редирект на /dashboard/bots
  dashboard/
    layout.tsx                 # сайдбар + main
    bots/page.tsx              # список ботов
    bots/[id]/                 # страница бота (вкладки + чат)
    <раздел>/page.tsx          # заглушки второстепенных разделов
  api/chat/route.ts            # POST: сообщение + конфиг бота -> ответ
components/                    # Sidebar, Topbar, BotTraining, ChannelsPanel,
                               # BalancePanel, ChatWidget, icons
lib/                           # types, models (тарифы), ai (логика ответа)
```
